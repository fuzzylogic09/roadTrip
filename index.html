Sign in with your Google account to save trips in your Drive (RoadTripPlanner folder).

⚙️ Developer setup
  1. console.cloud.google.com → New project
  2. Enable Google Drive API + Identity API
  3. Credentials → OAuth 2.0 Web Client → HTTPS domain
  4. Replace YOUR_CLIENT_ID in app.js config
  5. Host on HTTPS (GitHub Pages / Netlify = free)
